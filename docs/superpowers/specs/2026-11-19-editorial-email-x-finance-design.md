# Horizon 编辑部日报、X 热点与财经栏目设计

## 目标

把 Horizon 邮件改成更易读的中文编辑部日报，并在现有内容之外增加中文圈 X 讨论和覆盖 A 股/港股、美股科技股、全球宏观的财经新闻。邮件继续提供纯文本版本；现有 GitHub 近 24 小时新增 Star 前 20 名栏目继续保留。

## 已确认的用户规则

- 邮件版式：单列编辑部日报，分栏清楚、内容卡片易扫读。
- X 范围：中文 AI、开源项目和开发者讨论。
- X 口径：按过去 24 小时筛选，按互动热度排序；每天最多展示 10 条。
- X 抓取上限：搜索“AI Agent”和“开源 AI”两个主题词，每个词最多获取 30 条。
- 财经市场：A 股/港股、美股科技股、全球宏观。
- 数据方案：Apify X 搜索 + RSS 财经新闻。
- GitHub 热门栏目保持现有规则：过去 24 小时新增 Star 榜、最多 20 个项目、中文说明。

## 内容和数据方案

### X 热点

使用 Horizon 的 Apify 抓取器和 APIFY_TOKEN 环境变量，默认调用社区维护的 Xquik Actor。启用关键词搜索，搜索词为“AI Agent”和“开源 AI”；停用当前配置中的个人账号列表，避免无关的英文人物动态混入。请求使用中文语言过滤和 Latest 搜索排序，每个词最多返回 30 条，两个词共用一个 actor run，合计最多 60 条。

抓取后将两组结果合并，按 Tweet ID 去重，并仅保留最近 24 小时发布的帖子。互动热度使用点赞数 × 2 + 转发数 × 3 + 回复数 × 2；热度相同时优先较新的帖子。合并后最多保留 10 条传入 AI 处理，避免无关帖子占用摘要分析。阅读量可随互动数据展示，但不参与主排序，避免不同账号的曝光规模压过实际互动。

新增独立的 x-hotspots profile，使用 5.0 的最低相关性分数（该 profile 将 0–4 定义为信息稀少、偏题或以推广为主），低于普通科技新闻的 7.0 门槛，并关闭主题去重。AI 只根据原帖及抓取到的公开互动信息，用中文解释讨论的主题和上下文；原帖没有提供的事实不得补写。邮件条目展示作者、发布时间、点赞/转发/回复数和原帖链接。关闭回复抓取，避免增加额外 Apify 调用。

### 财经新闻

保留当前已启用的 CNBC Finance RSS。另在现有 RSS 列表中增加 3 个 Google News RSS 搜索源，统一设为简体中文并路由到 finance-news：

1. A 股/港股：查询 A 股和港股市场动态。
2. 美股科技股：查询美股科技公司、科技股和纳斯达克相关报道。
3. 全球宏观：查询全球宏观经济、美联储、通胀和利率相关报道。

所有财经 RSS 项目沿用 Horizon 的过去 24 小时收集窗口和现有 finance-news 分析、重要性阈值及主题去重设置。栏目提供新闻摘要和来源链接；本次不增加行情报价、投资建议或收益预测。

### 邮件版式

邮件主体采用适合常见邮件客户端的窄单列布局，内容宽度约 640px。视觉层级为深海军蓝标题栏、浅色页面背景、青绿色强调色、清晰的栏目标题和逐条新闻卡片；顶部显示中文标题、日报日期和最多 3 条今日重点。正文按 GitHub 热门、科技/开发者、X 热点、财经等栏目分组。条目卡片保留标题、中文摘要、来源、时间和链接等现有信息；X 卡片另外展示互动数据。

HTML 使用表格作为主要布局结构和行内样式，不依赖外部字体、图片或样式表。现有安全的 Markdown 内容处理继续作为输入边界。MIME multipart/alternative 同时发送纯文本和 HTML，两者内容一致；邮件主题包含日报名称和日期，退订说明按邮件语言显示，并准确提示向当前邮箱发送主题完全匹配退订关键词的新邮件。

## 文件与数据流

- profiles/x-hotspots/: 独立 X 热点 profile、中文分析和说明规则。
- profiles/finance-news/: 沿用现有财经 profile，不改变其评分与主题去重策略。
- data/config.json: 本机忽略跟踪配置中启用 Xquik 搜索，设置两个关键词、每词最多 30 条、profile 5.0 阈值和路由；保留 CNBC 并增加 3 个财经 RSS 查询源；把 X 与财经栏目加入日报顺序。APIFY_TOKEN 仅放在本机环境变量中。
- src/scrapers/twitter.py: 尊重每关键词配置的抓取上限，传入中文语言条件，对合并结果去重、过滤 24 小时窗口、计算互动热度并截取前 10 条。
- src/ai/summarizer.py: 注册并显示 X 独立栏目，按互动热度维持其条目顺序；条目元数据中的互动数和链接直接渲染，避免模型改写数值。
- src/services/email.py: 保留现有纯文本 MIME 部件，增加邮件专用的表格布局、顶部重点摘要、栏目和条目卡片及行内样式。
- 每日数据流：Apify X 和 RSS 财经源抓取 → 时间过滤与去重 → profile 分析 → 按栏目生成日报 Markdown → 生成邮件 HTML 与纯文本 → 沿用既有 SMTP 发送任务。

## 空数据和失败处理

- APIFY_TOKEN 未设置时记录清晰的警告并跳过 X 抓取；不影响 GitHub、RSS 或邮件发送。X 栏目无可展示帖子时，邮件显示明确的空栏目提示，不生成虚构内容。
- Apify 请求失败时记录来源和错误，并继续处理其它来源；日报中的 X 栏目显示数据暂不可用或无可展示内容。
- RSS 抓取器现有逐源错误隔离保持不变。某个财经 feed 失败时，其它 feed 和日报继续运行；财经栏目没有可展示新闻时显示空栏目提示。
- 市场类新闻只呈现来源报道，不把它包装成实时行情或投资建议。
- HTML 邮件渲染失败时，发送流程仍保留可用的纯文本备用内容；SMTP 投递流程和收件人管理不变。

## 验收标准

1. 本机配置启用两个中文主题搜索词、每词最多 30 条、过去 24 小时过滤和最多 10 条输出；X 结果归入 x-hotspots，不再抓取默认个人账号。
2. X 条目按确定的互动热度排序，重复帖子只出现一次，中文说明来源于原帖，不虚构背景，展示作者、发布时间、互动数据和帖子链接。
3. 财经栏目包含 CNBC 和 A 股/港股、美股科技股、全球宏观三个 RSS 搜索源，并路由到 finance-news；原有财经评分设置保持不变。
4. 邮件保留普通文本和 HTML 两种 MIME 内容；HTML 使用单列、分栏卡片、日期与重点摘要，主要布局使用表格且样式行内化。
5. APIFY_TOKEN 缺失、X 抓取失败或单个 RSS 源失败时，其它来源仍继续；相应栏目不会生成虚构新闻或行情。
6. 现有每日邮件投递、退订说明及 GitHub 每日新增 Star 前 20 名栏目的规则不变。
