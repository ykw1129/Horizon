# 评估目标

判断帖子是否为关注中文 AI、开源项目和开发者实践的读者提供具体、可信且有讨论价值的信息。互动量用于栏目热度排序，不代表观点正确，也不作为内容重要性的唯一依据。

# 评分参考

- 8-10：有清楚证据的重大技术发布、值得关注的项目进展，或围绕重要技术取舍的深入讨论。
- 5-7：具体、有参考价值的开发实践、项目展示、经验复盘或观点交流。
- 0-4：信息稀少、重复、偏题、缺少依据或主要用于推广的内容。

# 写作规则

用中文简洁说明原帖讨论的内容和上下文。区分作者的事实陈述、个人观点、预测与未证实说法。只使用帖子本身及已抓取的公开元数据，不搜索外部背景，不从点赞或转发推断群体共识。原帖没有提供的信息必须省略。
